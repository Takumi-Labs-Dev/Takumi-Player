## ✨ Overview

**匠 ¦ Takumi Player** is a beautifully crafted music player built with a focus on **aesthetic clarity, smooth interaction, and immersive minimalism**.

Designed with a **dark, refined UI**, Takumi Player delivers a distraction-free listening experience while maintaining powerful functionality under the hood.

---

## 🎨 Design Philosophy

> *“Perfection is achieved not when there is nothing more to add, but when there is nothing left to take away.”*

* 🖤 **Near-black foundation** — calm and focused
* 🪶 **Soft typography hierarchy** — elegant and readable
* 🥇 **Gold accent system** — subtle but expressive
* 🎧 **Fluid motion** — smooth, intentional animations

---

## 🚀 Features

### 🎵 Core Playback

* High-quality audio playback
* Smooth track switching
* Clean, distraction-free UI

### 🎛️ Visual Experience

* Spinning disc animation while playing
* Dynamic playback bars replacing track numbers
* Hover-responsive progress bar (3px → 5px)

### 📂 Playlist System

* Sidebar-based playlist navigation
* Active playlist highlighted with gold border
* Minimal and intuitive layout

### 🎯 UI/UX Details

* Frameless window with custom draggable titlebar
* Soft glow on active navigation
* Lightweight separators using translucent borders
* Carefully tuned spacing and alignment

## 🧩 Theme System

Takumi Player uses a carefully designed color system:

| Role       | Value   | Description     |
| ---------- | ------- | --------------- |
| Background | #0a0a0c | Deep near-black |
| Surface    | #111116 | Panels & layout |
| Accent     | #c8a96e | Primary gold    |
| Accent 2   | #e8c98e | Hover gold      |
| Text       | #e2ddd6 | Warm off-white  |
